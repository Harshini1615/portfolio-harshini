# Sri Harshini Botcha — Data Science Portfolio

A dark, glassmorphic personal portfolio built for hackathon applications, showcasing Data Science coursework, an analytics internship, projects, and certifications.

## Structure
```
.
├── index.html      # Page content
├── css/style.css   # Styling, layout, scroll-reveal states
└── js/script.js    # Active nav highlighting + scroll-reveal animation
```

## Running locally
Just open `index.html` in a browser — no build step needed.

For GitHub Pages:
1. Push this repo to GitHub.
2. In repo Settings → Pages, set the source branch to `main` and folder to `/ (root)`.
3. Your site will be live at `https://<username>.github.io/<repo-name>/`.
